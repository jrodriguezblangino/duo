# Lista Curada de Prospectos — Revestimientos (AR)

**Criterio de selección (filtro de senior, no cantidad):**
1. Rubro = revestimiento / panel / fachada / construcción en Argentina.
2. Web débil o genérica (Wix/template, sin foco, sin prueba social) = gap alto = troiano fácil.
3. Canal de contacto público (WhatsApp o Instagram) = alcanzables en frío.
4. Tamaño = PyME / mediana, dueño alcancable (no corporativo con marketing depto).

**Descartados a propósito:** Alsafex (web WordPress corporativa seria, no hay gap),
fábricas de China (tu blanco es AR/local), Hunter Douglas (multinacional, inalcanzable).

**Cómo usar esta lista:** para cada uno, antes de escribirle, entrá a su IG y mirá 1–2
reels/obras para sacar la "observación real" del abridor (patrón acordado: reel/obra +
"soy diseñador web, metiéndome en construcción" + "su web se ve un toque vieja, le queda
grande" + "le armé una maqueta con su marca" + ¿le paso el link?).
